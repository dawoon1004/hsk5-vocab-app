## 🌟 주요 특징

1. **📚 교재 스캔본 100% 정합성 어휘 탑재**
   - 1강 가정, 일상생활 (001~045) 및 2강 외모, 패션 (046~060)
   - 교재 고유의 **한자 부수 파자 연상 암기 비법(💡)** 및 실전 예문 수록

2. **⚡ 26초 스타일 5단계 완벽 학습 루프**
   - **1단계 스키밍**: 감성 2D 일러스트 + 원어민 음성 자동재생(단어 ➔ 예문)으로 빠르게 눈에 익히기
   - **2단계 플래시카드**: 앞면 한자 보고 떠올린 후, 뒷면에서 뜻·예문·연상비법 확인 & 3단계 SRS 복습
   - **3단계 결과 분석**: 정답률, 학습 속도, 취약 단어 확인 및 가리기 훈련
   - **4단계 듣기 모드**: 단어 ➔ 한국어 뜻 ➔ 예문이 멈추지 않고 흘러나오는 연속 플레이어
   - **5단계 실전 퀴즈**: 8문항 빈칸 채우기 기출 퀴즈 (시간제한 & 오답 복습)

3. **📅 실제 오늘 날짜 연동 & 데일리 자동 진도**
   - 기기의 실제 오늘 날짜와 실시간 연동 (주간 달력 바 제공)
   - 하루 6단어 기준: 전날 학습 완료 시 다음 날 새로운 단어 6개가 자동으로 오픈!

4. **📱 모바일 & 반응형 최적화**
